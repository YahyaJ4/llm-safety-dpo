# LLM Safety & Alignment via DPO

A machine learning project investigating safety-capability tradeoffs in large language models using Direct Preference Optimization (DPO).

## Overview

This project explores how preference optimization can improve model safety while preserving general reasoning and task performance.

The work focuses on fine-tuning and evaluating large language models across safety and capability benchmarks to understand how alignment choices affect downstream behavior.

## Key Ideas

- Supervised fine-tuning
- Direct Preference Optimization (DPO)
- Safety alignment
- Refusal behavior
- Capability retention
- Benchmark-based evaluation

## Models & Methods

- Llama 3.1 8B
- Qwen 2.5 7B
- LoRA fine-tuning
- DPO training
- Safety and capability evaluation

## Evaluation

The project compares model behavior across:

- Safety/refusal benchmarks
- General knowledge evaluation
- Mathematical reasoning evaluation

## Technologies

- Python
- PyTorch
- Hugging Face Transformers
- LoRA / PEFT
- DPO
- Linux / HPC
